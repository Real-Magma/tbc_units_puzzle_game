How to Play

利用記憶，拼出八親不認的貓咪吧！

加入角色與敵人

選擇後點一下加入；可搜尋名稱或編號。

移動、縮放與旋轉

拖曳移動、拉四角縮放、圓點旋轉。

選取、多選與群組

Ctrl 多選；可群組或解除群組。

上一步與下一步

Ctrl + Z 復原，Ctrl + Shift + Z 重做。

圖層順序

↑／↓ 或 W／S 調整前後；Shift 直達頂／底。

複製與貼上

Ctrl + C 複製，Ctrl + V 貼上。

左右反轉

按 F 或選單可左右反轉。

刪除與清空

Delete、Backspace 或垃圾桶刪除；長按清空。

畫布縮放與回原點

滾輪／雙指縮放；房子回原點。

物件功能選單

右鍵或長按物件，開啟進階操作。

PS 圖層面板

開啟 PS 欄位可選取與排序圖層。

儲存圖層

更多 → 儲存圖層，下載目前配置。

匯入圖層

更多 → 匯入圖層，還原先前配置。

複製與分享圖片

更多 → 複製或分享主畫面圖片。

評分模式

設定條件後開始，完成後按評分。

切換明暗主題

按月亮／太陽切換明暗主題。

音效與音量

喇叭開關音效；滑桿調整音量。

消息

點左上 Logo 查看消息與網站資訊。
